# AI Usage Statement

The team used an AI coding assistant (Claude Code by Anthropic) as a tool during the
preparation of pre-defense 1. This statement describes what it was used for and what was
done by the team.

## What the assistant was used for

- Drafting and structuring the text of the documentation in `docs/`.
- Searching for literature and cross-checking bibliographic data (DOIs).
- Generating PlantUML code for the diagrams and the markup of the clickable prototype.
- Helper scripts for the Git workflow (branch, commit, pull request).
- Consistency checks between documents (requirement IDs, references, deadlines).

## What was done by the team

- Choice of the topic, the scope and the target users.
- Interview with a dentist (in person, with the prototype) and interviews with four
  potential users; the notes in `docs/interviews/` are based on these conversations.
- Decisions on the architecture, technologies and evaluation approach.
- Review of every pull request by the other team member before merging.
- Verification of the literature sources and final responsibility for all content.

## Note on the commit history

The assistant automatically added itself as a co-author ("Co-authored-by: Claude") to two
commits (DIP-7 and DIP-11). The trailer was removed from the history on 21.10.2026; the
contributors list in the GitHub sidebar may still show it until GitHub refreshes its data.
